Este site não tem contas, cookies nem anúncios. Ele é um conjunto de páginas estáticas, e conta as visitas sem saber quem você é.

## Onde o site fica hospedado

O site é servido pelo [Cloudflare Pages](https://pages.cloudflare.com/). Como qualquer servidor web, a Cloudflare recebe o seu endereço IP e os dados do seu navegador quando você abre uma página. A [Política de Privacidade da Cloudflare](https://www.cloudflare.com/privacypolicy/) diz o que a Cloudflare faz com eles. As cópias de prévia do site, feitas para os pull requests, são servidas do mesmo jeito e ficam fora dos buscadores.

## Como as visitas são contadas

O site usa o [Cloudflare Web Analytics](https://www.cloudflare.com/pt-br/web-analytics/) para contar as visualizações de página e medir o tempo de carregamento. Cada página carrega um script pequeno da Cloudflare (`static.cloudflareinsights.com`). Ele não grava cookies, não usa o armazenamento do seu navegador e não acompanha você entre sites. A Cloudflare mostra só totais, como visualizações por página, países e tempos de carregamento, nunca dados de um visitante específico.

## O que fica no seu navegador

O site guarda algumas escolhas no armazenamento local do seu navegador, para elas continuarem lá na próxima visita. Elas nunca saem do seu navegador:

- o tema (claro ou escuro),
- o idioma, quando o site escolheu português para você ou você escolheu um,
- a aba que você escolheu num grupo de abas, como a sua linguagem de programação.

Limpar os dados do site no navegador apaga tudo isso.

## Quando o site fala com outros serviços

Fora a contagem de visitas acima, a maioria das páginas não carrega nada de fora deste site. A busca roda no seu navegador, num índice que vem com o site. As caixas "Teste com JavaScript" rodam a biblioteca JavaScript deste site.

Algumas coisas carregam de outros serviços, e só quando você as abre:

- **Os exemplos interativos** dos guias carregam a biblioteca JavaScript e os frameworks (React, Vue, Angular) do [jsDelivr](https://www.jsdelivr.com/terms/privacy-policy-jsdelivr) e do [esm.sh](https://esm.sh/).
- **O exemplo de endereço** envia o CEP que você digita para serviços públicos de CEP (ViaCEP, BrasilAPI e WideNet) para achar o endereço. É o que a busca de endereço da biblioteca faz.
- **A página Time** mostra fotos de perfil servidas pelo GitHub.

## As bibliotecas

As bibliotecas do [Brazilian Utils](https://github.com/brazilian-utils) rodam dentro do seu programa e não enviam nada para lugar nenhum. As únicas exceções são as duas consultas de CEP, `cep.getAddressInfo` (o endereço de um CEP) e `cep.getInfoByAddress` (os CEPs de um logradouro), que consultam serviços públicos de CEP pela internet.
